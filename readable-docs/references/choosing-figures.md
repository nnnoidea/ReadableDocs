# 按读者问题选图

先确定读者的问题，再识别要表达的组成、联系、过程或数值关系，最后选择能让这种关系直接可见的图形。

按核心说明点选图：总览图说明整体，局部图解释具体关系或机制。用图建立阅读主线，文字补足解释和条件。先确定信息应怎样被看见，再选择绘制组件与工具。

## 对象与关系图

| 类别 | 读者的问题 | 适合的图 | 主要视觉表达 |
| --- | --- | --- | --- |
| 组成与包含 | 它由什么组成？什么属于它？ | 组成图、嵌套框图 | 大框包含小框 |
| 层级与分层 | 谁属于哪一级？各层承担什么？ | 树状图、分层图 | 父子分支、上下分层 |
| 范围与交集 | 哪些相同、哪些独有、哪些重叠？ | 集合图、交集图 | 区域及其重叠 |
| 联系与依赖 | 哪些对象有关？谁依赖谁？ | 局部关系图、依赖图 | 连线、带关系标签的箭头 |
| 对应与分配 | 哪个对象对应哪个对象？谁负责哪些项？ | 映射图、对应矩阵 | 两侧对齐连线、行列交叉 |
| 步骤与决策 | 先做什么？遇到条件走哪条路？ | 流程图、决策树 | 有向路径与分支 |
| 职责与交接 | 谁在做？工作怎样交给下一方？ | 泳道图、时序图 | 按参与方分区，呈现动作或消息 |
| 状态与转换 | 当前处于什么状态？什么条件使它改变？ | 状态图 | 状态节点、标注触发条件的箭头 |
| 时间与安排 | 什么时候发生？持续多久？哪些同时进行？ | 时间线、甘特图 | 时间轴、持续区间 |

### 相近形式如何选择

- 突出整体内部的组成，使用包含框；突出多级归属，使用树；突出各层职责，使用分层布局。
- 突出执行动作与路径，使用流程图；突出对象所处的状态和变化条件，使用状态图。
- 突出各方承担的工作，使用泳道图；突出消息往返及先后，使用时序图。
- 关系较少、需要追踪连接时，使用关系图；对象较多、需要逐项核对时，使用对应矩阵。
- 关联用连线，包含用框内布局，有明确方向的依赖或流转用箭头。连线与箭头的标签说明具体含义。

## 数据图表

| 类别 | 读者的问题 | 适合的图 | 选择依据 |
| --- | --- | --- | --- |
| 数量与差异 | 谁更多？相差多少？ | 条形图、柱状图、点图、差值图 | 比较类别的数值 |
| 占比与构成 | 各部分占整体多少？构成有什么变化？ | 饼图、环形图、堆叠条形图、百分比堆叠图 | 整体口径明确；多组构成优先并排比较 |
| 趋势与变化 | 数值随时间或规模怎样变化？ | 折线图、面积图 | 横轴具有连续或有序含义 |
| 分布与波动 | 数据集中在哪里？离散程度如何？ | 直方图、箱线图 | 观察一组数据的分布 |
| 变量关联 | 两个数值变量是否一起变化？ | 散点图 | 每个点对应同一对象的两个数值 |
| 多维模式 | 哪些组合更高、更低？哪里集中？ | 热力图 | 用行列组织组合，用颜色表达数值 |

组成图回答“由哪些部分组成”，占比图回答“各部分占多少”。仅表达成员归属时，用包含框；有数值依据且需要比较占比时，按比例划分区域或长度。精确数值的逐项核对可以使用表格。

## 确定范围，再选择绘制方式

局部图可以采用上述任一种形式，范围以当前段落需要解释的信息为准，放在相关内容附近。需要整体认识时，呈现足以回答该问题的全貌。

先选表达形式，再查[模板目录与填写说明](drawing.md)。优先填模板生成；模板参数、图型调整或拆分仍无法表达时，再定制绘制。包含、交集、映射、矩阵、时间线、甘特、热力、堆叠、差值及多面板均有填内容模板。实际渲染检查沿用 Skill 中的准确性、顺序阅读和理解收益要求。
