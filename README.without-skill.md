# ReadableDocs

**让 Agent 按你的要求，把难懂的文档改成读者看得懂、用得上的样子。**

ReadableDocs 是一个文档写作与改写 Skill，当前版本 **0.0.1**。适合用 Agent 写平台介绍、使用说明、研究交接和知识解释的人：告诉它写给谁、读完要做什么、哪些信息必须保留，它会据此调整内容、顺序和表达。

它以图为主要表达、文字为辅助，用图讲清结构、流程和数据，配文补充必要解释与条件。

## 开始使用

把本项目的 [`readable-docs/`](readable-docs/) 文件夹放到 Agent 能读取的位置，然后把原文或资料交给它，并发送：

```text
请读取 readable-docs/SKILL.md，使用 ReadableDocs 改写这份文档。

原文：./原文.md
读者：第一次接触这个项目的同事。
目标：读完知道项目能做什么，以及怎样开始使用。
要求：简洁，先突出最重要的信息；解释必要术语，
      用图讲清关键结构与步骤，保留原文中的限制条件。
输出：./改写版.md 及引用的图片。
```

路径替换成你的实际位置。也可以进一步指定篇幅、输出格式、必须保留的数据，或指出“这一段仍然看不懂”，让 Agent 按新的要求继续修改。

## 它会怎样改

- **重点埋得太深**：先呈现读者需要的结论，再展开必要背景和细节。
- **术语太多、读到后面忘了前面**：先解释再使用，把条件和解释放在需要它们的位置。
- **一大段文字讲不清关系**：用结构图、流程图或数据图呈现，删去重复配文。
- **简化后丢了关键信息**：保留影响结论和行动的条件，缺少依据的内容明确标注。

最终交付正文和图示；草稿、图源及检查记录作为本地过程材料保留，便于追溯修改。

## 绘图与环境

项目附带 **25 种绘图模板**，涵盖结构、流程、时序、比较和数据分布。Agent 填入实际内容后，使用 Python 3 标准库生成 SVG；自带的 PNG 预览脚本需要 macOS Quick Look 和 Pillow。

使用前确认 Agent 能读取本地文件；生成图示时还需能运行 Python。更多细节见 [Skill 说明](readable-docs/SKILL.md)和[绘图说明](readable-docs/references/drawing.md)。
